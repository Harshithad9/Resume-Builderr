📝 WHAT YOUR BACKEND NEEDS
═══════════════════════════════════════════════════════════════════════════════

Models:
  ✓ User: { name, email, password, createdAt }
  ✓ Resume: { userId, fullName, email, phone, linkedIn, github, ... }

Endpoints:
  ✓ POST   /api/auth/register      (create user)
  ✓ POST   /api/auth/login         (verify & return token)
  ✓ GET    /api/resume             (get user's resumes)
  ✓ POST   /api/resume             (create resume)
  ✓ PUT    /api/resume/:id         (update resume)
  ✓ DELETE /api/resume/:id         (delete resume)

Middleware:
  ✓ CORS enabled for http://localhost:5173
  ✓ JWT authentication for protected routes

🐛 DEBUGGING STEPS
═══════════════════════════════════════════════════════════════════════════════

1. Open DevTools: F12 (Windows) or Cmd+Option+I (Mac)

2. Go to Network tab

3. Try action (signup, login, create resume)

4. Look for failed requests (red)

5. Click the request to see details:
   - Headers: Check Authorization header
   - Request: What data was sent
   - Response: What backend returned
   - Status: HTTP status code

6. Read the error message carefully - it usually says what's wrong

7. Common errors:
   ✗ 404 Not Found    → Endpoint doesn't exist
   ✗ 400 Bad Request  → Validation failed
   ✗ 401 Unauthorized → Token is invalid
   ✗ 500 Server Error → Backend has a bug

═══════════════════════════════════════════════════════════════════════════════

   ↓

   ↓

   ↓

   ↓

   ↓

   ✓ Validates email not taken
   ✓ Hashes password
   ✓ Creates user in MongoDB
   ✓ Generates JWT token
   ✓ Returns { token, user }
   ↓
8. Frontend receives response
   ✓ Stores token in localStorage
   ✓ Saves user in context
   ✓ Redirects to /login or /dashboard
   ↓
9. User is now logged in!


🔐 HOW TOKENS WORK
═══════════════════════════════════════════════════════════════════════════════

1. User logs in
   → Backend returns JWT token: "eyJ..."

2. Frontend stores token in localStorage:
   localStorage.setItem('token', 'eyJ...')

3. For every API request, Axios interceptor adds token:
   Authorization: eyJ...

4. Backend receives request, validates token:
   ✓ If valid: Process request, return data
   ✗ If invalid: Return 401 Unauthorized

5. Protected pages check for token:
   ✓ If exists: Show page
   ✗ If missing: Redirect to login

🆘 QUICK TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Problem                          Solution
───────────────────────────────────────────────────────────
Cannot reach backend             • Check backend is running
                                 • Verify port in API URL
                                 • Check CORS is enabled

CORS error                       • Add CORS middleware to backend
                                 • Make sure origin is correct

Login doesn't work               • Check token in response
                                 • Open DevTools Network tab
                                 • Look at error message

Dashboard is blank               • Check localStorage for token
                                 • Verify GET /api/resume works
                                 • Check Authorization header sent

Form won't submit                • Open DevTools Console
                                 • Look for error messages
                                 • Check Network tab for failed request

Still stuck?                     • Read BACKEND_SETUP_GUIDE.md
                                 • Copy code from BACKEND_EXAMPLES.md
                                 • Post error message to Stack Overflow
