   - POST   /api/auth/register
   - POST   /api/auth/login
   - GET    /api/resume
   - POST   /api/resume
   - PUT    /api/resume/:id

   If on different port: Edit src/services/api.ts

4. Start both servers:
   Terminal 1: pnpm dev
   Terminal 2: npm start

5. Open http://localhost:5173
   Click "Get Started"
   Fill signup form
   → If it works, you're connected! 🎉


⚙️ CRITICAL: UPDATE API URL
═══════════════════════════════════════════════════════════════════════════════

File: src/services/api.ts

Default (localhost:5000):
  const API = axios.create({
    baseURL: 'http://localhost:5000/api',
  })

If your backend is on a different port, change it:
  const API = axios.create({
    baseURL: 'http://localhost:YOUR_PORT/api',
  })

⚠️ THIS IS THE MOST COMMON MISTAKE - DON'T SKIP!


🔒 CORS: CRITICAL FOR BACKEND
═══════════════════════════════════════════════════════════════════════════════

Add this to your backend's Express app:

const cors = require('cors');

app.use(cors({
  origin: 'http://localhost:5173',
  credentials: true,
  methods: ['GET', 'POST', 'PUT', 'DELETE'],
  allowedHeaders: ['Content-Type', 'Authorization']
}));

Without this, you'll get CORS errors!

2. Check network requests: F12 → Network tab
3. Try the action again while Network tab is open
4. Look for red requests (failed)
5. Click the request to see response
6. Read the error message
7. Look up the error in BACKEND_SETUP_GUIDE.md Troubleshooting

Most problems are covered in the guides!
