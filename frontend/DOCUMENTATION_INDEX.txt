🎯 QUICK REFERENCE

Frontend Details:
  • Runs on: http://localhost:5173
  • Dev command: pnpm dev
  • Built with: React, Vite, React Router, Tailwind CSS, Axios

Backend Requirements:
  • Runs on: http://localhost:5000 (configurable)
  • Tech: Express.js, MongoDB, JWT
  • Must have 6 endpoints:
    - POST   /api/auth/register
    - POST   /api/auth/login
    - GET    /api/resume
    - POST   /api/resume
    - PUT    /api/resume/:id
    - DELETE /api/resume/:id

Setup Time: ~30 minutes (if backend exists)
            ~1-2 hours (if building backend from scratch)
