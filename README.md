# AI-Based Resume Builder

A professional Resume Builder web application developed using the MERN Stack. The application allows users to create, manage, preview, and download resumes dynamically through a modern and responsive user interface.

## Features

- User Registration and Login
- Secure Authentication System
- Dynamic Resume Creation
- Live Resume Preview
- Resume PDF Download
- Responsive User Interface
- Resume Management System
- Professional Resume Templates
- CRUD Operations using MongoDB

## Tech Stack

### Frontend
- React.js
- TypeScript
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js

### Database
- MongoDB Atlas
